# whid-site-nuxt

A site built in Nuxt for fun!

## Installation & Usage

```bash
npm install --force # The "force" is needed because Nuxt 2 is not compatible with current tooling
npm run dev
```

## Running in Production

```bash
npm run build
npm run start
```
